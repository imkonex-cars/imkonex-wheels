# Проверка версии 0.2.0

Источник данных: успешный пользовательский отчёт 1.3, завершённый 17.09.2026 19:23:46 UTC. Семь read-only вызовов, обе категории verified, 41 склад в ответе GetWarehouses. В витрину перенесено 6 проверенных товаров и только их предложения.

Проверены экспорт публичных полей без закупочных цен, отсутствие подстановки закупочной цены вместо отсутствующей розничной, XL, строковые артикулы, отказ для неподтверждённой валюты и неоднозначных складов. Сборка ограничивает схему и домены фотографий.

Функциональные проверки DOM охватывают прежний деморежим и новую выборку: фильтры, поиск, карточку, сравнение, выбор одного склада для комплекта, корзину, сохранение расчёта, маркировку источника цен, заглушку фотографии, запуск как локальный файл и отсутствие постоянного хранилища браузера.

Результаты: 16 тестов JavaScript и 12 тестов экспортёра Python проходят. Сборка статического сайта и HTML для локального просмотра проверены. Дополнительно проверено исполнение встроенных скриптов готового HTML по адресу file:///.

Ограничения: функциональные браузерные проверки выполнены в jsdom, скриншотный прогон в Chromium не выполнен. Загрузка фотографий с сервера поставщика в этой среде не подтверждена; сохранены выданные API ссылки. Windows-браузер пользователя, аккаунт Render и исходящий доступ будущего серверного API к «4точки» здесь не проверялись.

Полная выгрузка, автоматическое обновление, ценообразование IMKONEX и оформление заказа этой версией не подтверждаются. Счётчики страниц поиска не использованы как точное число товаров.
