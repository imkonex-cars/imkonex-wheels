# Проверки версии 0.4.0

Подготовлено 21.09.2026. Размещение: исходный Static Site Render + GitHub Actions.

- 23 проверки JavaScript: публичный формат, фильтры, корзина, сохранённые расчёты, упаковка и интерфейс на 24 000 синтетических товаров. На страницу создаются 12 карточек, навигация ограничена; проверен переход на последнюю страницу и поиск точного артикула. DOM-проверка не является замером скорости в браузере клиента.
- 16 проверок нового импортера: нумерация страниц 0/1 и псевдоним страницы 0; сохранение всех артикулов; авторизация; валюта; повтор/пропуск страниц; полнота характеристик; неизвестные склады; недопустимые цены/остатки; ограничения объёма; отсутствие подстановки закупочной цены; счётчики исключений; исходные артикулы; неизвестный сезон; фото; атомарная замена; dry-run; исключение секретов; XML-запросы по сохранённой WSDL.
- 82 проверки существующего Python-кода: API и прежние диагностические/экспортные сценарии.
- По сохранённому отчёту поставщика сопоставлены все шесть исходных товаров: цены, предложения складов и характеристики совпадают с проверочной публичной выборкой. Оптовые поля для сравнения не публиковались.

Массовые авторизованные запросы из этой среды не выполнялись. Доступ с GitHub runner, допустимую частоту API, фактическое число товаров и публикацию результата на Render подтверждает первый пользовательский запуск workflow после заполнения Secrets.

В архив включена прежняя выборка из шести товаров с локальными фото и исходной датой 17.09.2026. Наличие кода синхронизации не означает, что новая выгрузка уже выполнена.
