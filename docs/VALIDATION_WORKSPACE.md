# Проверка полной рабочей области WORKSPACE-1

Дата: 21.09.2026. Версия приложения: 0.3.0. Формат: все исходники обычными файлами и папками; без вложенного SOURCE_CODE.zip.

## Проверено

- `node BUILD_RENDER.mjs`: успешная сборка 6 товаров в режиме snapshot.
- `npm run check`: синтаксис frontend/app.js и frontend/domain.js проверен успешно.
- `npm test`: 19 тестов JavaScript, 19 успешных, 0 ошибок.
- Архив распакован в отдельную пустую папку. `npm run build` в этой папке успешно собрал витрину без установки npm-зависимостей: самой сборке нужен только Node.js.
- На распакованной копии дополнительно выполнены три проверки tests/workspace.test.mjs: все успешны. Проверены публикация реального снимка при старом CATALOG_MODE=demo, запуск из другого рабочего каталога, очистка старого dist, отсутствие публикации серверных файлов и старого корневого index.html.
- При отсутствии frontend/domain.js или попадании приватного поля в публичный снимок сборка завершается ошибкой и сохраняет предыдущий dist.
- Собранная витрина загружает 6 реальных товаров, переключает категории и рассчитывает 4 Venti со склада Уфа 2 за 30 640 ₽ без доставки. Остальные проверки покрывают комплект Pirelli, ограничения остатков, фильтры, сравнение, корзину и сохранение расчёта.
- Проверены целостность ZIP и соответствие его состава FILES_MANIFEST.txt. В архиве отсутствуют вложенные ZIP, исходные API-отчёты, .env, .git, node_modules и виртуальные окружения.

Интерфейс проверен средствами jsdom под Node.js 24.19.0. Это функциональные проверки DOM и JavaScript, а не визуальная проверка настоящего браузера. Для Render в конфигурации указан Node.js 22.
