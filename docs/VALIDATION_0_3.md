# Проверка полной сборки 0.3.0

Дата: 17 сентября 2026 года. Проверялся пакет IMKONEX-WHEELS-0.3.0-FULL-1.

## Распаковка и сборка

- Архив распакован в отдельную папку, без исходников и зависимостей рабочего проекта.
- На первом уровне ровно 8 обычных файлов. Вложенный SOURCE_CODE.zip содержит исходники; для публикации его распаковывать не требуется.
- `npm ci --ignore-scripts --no-audit --no-fund` выполнен успешно; у готового пакета нет npm-зависимостей.
- `npm run build` успешно вызвал новый BUILD_RENDER.mjs. Результат: 6 товаров, snapshot, версия 0.3.0.
- Отдельно проверена целостность ZIP и отсутствие в исходниках приватных отчётов, рабочих .env, виртуальных окружений и node_modules. Публичный каталог проходит строгую проверку разрешённых полей.

## Четыре проверки новой упаковки

`tests/full_release.test.mjs`: 4 пройдены, 0 ошибок.

1. В копию пакета добавлен старый scripts/build.mjs, который намеренно выдаёт ошибку, и задан CATALOG_MODE=demo. Новый BUILD_RENDER.mjs успешно собрал 6 реальных товаров. Посторонний файл, предварительно добавленный в dist, удалён при сборке; исходники не опубликованы. Все три скрипта и таблица стилей вынесены в локальные файлы с хешами в именах.
2. Пакет работает с BOM и переносами строк Windows. Изменение index.html без соответствующего обновления сборщика вызывает понятную ошибку; предыдущий dist сохраняется.
3. На собранной витрине проверены баннер с 6 товарами, версия 0.3.0, расчёт 4 Pirelli за 132 200 ₽ со склада Домодедово и 4 Venti за 30 640 ₽ со склада Уфа 2. Добавление пятого Venti блокируется остатком выбранного склада. Сохранённый расчёт содержит артикул и происхождение розничной цены.
4. Самостоятельный index.html проверен с адресом file:// и недоступным постоянным хранилищем: переключение на диски и сохранение расчёта работают в памяти страницы.

Проверки интерфейса выполнены в jsdom под Node.js 24.19.0. Это проверка DOM и JavaScript, а не визуальная проверка настоящего браузера. Для сборки указан Node.js 22+; npm-библиотеки при публикации не нужны.

Для повторения из каталога исходников:

```text
npm ci
python scripts/package-github.py
node --test tests/full_release.test.mjs
```

Можно задать переменную IMKONEX_RELEASE_DIR с путём к отдельно распакованному полному архиву; проверки используют эту копию.
