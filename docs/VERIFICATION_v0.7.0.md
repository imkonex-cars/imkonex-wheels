# Проверка 0.7.0

- 140 Python-тестов, 15 дополнительных сценариев: импорт API, сохранность базы, закрытые цены, правила по категориям, минимальный доход, покупательские заявки и статусы.
- 34 JavaScript-теста: настоящий граф ES-модулей в DOM, категории, два размера осей и комплект 2+2, кабинет, предпросмотр массовых цен, оформление, обычная корзина/фильтры/подбор автомобиля, сборка полной рабочей области.
- Контроль синтаксиса JS и сборка на имеющейся выгрузке из 20 359 реальных товаров.
- Повторная/параллельная отправка заявки создаёт одну запись. Изменение закупки до отправки блокирует старую сумму. Подмена клиентом цены не принимается.
- Исправленный подвал сохраняет три офиса и адреса; активные атрибуты событий и посторонние скрипты удаляются.
- Браузерная проверка пиксельного отображения локальной версии в этой среде недоступна. Адаптивность реализована CSS, интерактивные сценарии проверены в DOM; окончательный визуальный просмотр нужен после установки на REG.ru.
- Актуальный сервер до установки отвечает версией 0.6.0. Живой API поставщика и действующий менеджерский аккаунт из этой среды не использовались.
