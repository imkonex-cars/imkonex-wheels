# Проверка версии 0.1.0

## Выполнено

| Проверка | Результат |
|---|---|
| Синтаксис JavaScript | `npm run check` — успешно |
| Сборка витрины | `npm run build` — 72 варианта, все изображения найдены |
| JavaScript | 10 проверок — успешно |
| Python / API | 15 проверок — успешно |
| Автономный HTML | Код и изображения встроены, загрузка внешних модулей не требуется |
| Источники изображений | Шесть фотографий проверены визуально, источники сохранены |

Сценарии JavaScript проверяют в том числе переход от карточки к корзине и тестовой заявке, локальный кабинет, фильтры в URL, сравнение одной категории, сохранение размера и экранирование пользовательского ввода. Они выполняются в jsdom, а не в полноценном браузерном движке.

API проверен на демонстрационном наборе: фильтрация и страницы, серверный пересчёт, остаток целого комплекта на одном складе, отказ в дробном/отрицательном количестве и подменённой цене, отказ при дублирующихся строках, авторизация служебного endpoint, запрет заказов, отбрасывание приватных полей, проверка целостности снимка и ограничения SOAP-клиента.

## Не проверено в этой среде

- Публикация в реальном GitHub/Render-аккаунте: подключения ещё нет.
- Контейнерный запуск, PostgreSQL, миграции и восстановление дампа: Docker и сервер БД отсутствуют.
- Авторизованная работа 4tochki, реальные поля и коды ответов: доступ для интеграционного теста не настроен.
- Вёрстка в Chrome/Safari/Firefox и на физических телефонах, доступность скринридером, Core Web Vitals и нагрузка.

После публикации требуется проверить эти пункты по фактическому окружению. Утверждать превосходство над конкурентом по измеримым показателям до таких проверок нельзя.
