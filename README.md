# IMKONEX CARS · магазин шин и дисков 0.7.0

Витрина с подбором, защищённый кабинет, правила цен, клиентские подборки, заявки и статусы. Общая шапка и полный подвал основного сайта.

Состав обновления и поведение: [docs/UPDATE_v0.7.0.md](docs/UPDATE_v0.7.0.md). Проверки и границы готовности: [docs/VERIFICATION_v0.7.0.md](docs/VERIFICATION_v0.7.0.md).

Сборка: `node BUILD_RENDER.mjs`. Рабочий сервер REG.ru: `Dockerfile.portal`, `backend.portal:app`, переменные `PORT`, `MANAGER_DB_PATH`, `MANAGER_LOGIN`, `MANAGER_PASSWORD`, `FOURTOCHKI_LOGIN`, `FOURTOCHKI_PASSWORD`, `PUBLIC_ORIGIN`.

Проверка: `npm ci`, `npm run check`, `npm test`, `python -m pytest -q tests` после установки `requirements-dev.txt`.

Минимальный доход с единицы — 100 ₽ до расходов. Розница API применяется, когда выполняется этот минимум. Закупка и клиентские данные остаются в приватной БД сервера и не попадают в GitHub. Без актуальной закупки публичная цена не публикуется; приватный фоновый процесс обновляет цены для всех товаров.

Приём заявок работает с подтверждением менеджера. Онлайн-оплата и отправка уведомлений не подключены. Условия доставки и оплаты редактируются в кабинете. Отправка закупки поставщику требует существующего отдельного подтверждения и `SUPPLIER_ORDERS_ENABLED=true`.

Обновлять существующий проект с сохранением `data/supplier-snapshot.json`, фото и базы. Не заменять действующий проект старой выгрузкой из архивов.
