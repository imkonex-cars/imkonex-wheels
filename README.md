# IMKONEX CARS · каталог шин 0.6.0

Публичная витрина, закрытый кабинет менеджера, общая навигация основного сайта и клиентские подборки.

Пошаговая установка: [docs/UPDATE_v0.6.0.md](docs/UPDATE_v0.6.0.md).
Контракты API и ограничения первой расширенной выгрузки: [docs/API_FIELDS_v0.6.0.md](docs/API_FIELDS_v0.6.0.md).

Сборка: `node BUILD_RENDER.mjs`. Серверная версия: `Dockerfile.portal` и существующий комплект эксплуатации REG.ru. Точка входа `backend.portal:app`, порт из `PORT`, приватная база из `MANAGER_DB_PATH`.

Для проверки: `npm ci`, `npm run check`, `npm test`, `python -m pytest -q tests` после установки `requirements-dev.txt`.

Обновление сохраняет действующую `data/supplier-snapshot.json`, изображения и вынесенные за репозиторий секреты/базу. Приватные закупочные цены не записываются в публичную выгрузку или клиентские подборки.
