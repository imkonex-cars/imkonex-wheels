# IMKONEX CARS · каталог шин и дисков 0.9.0

Единая сборка для существующего магазина на REG.ru: витрина, кабинет менеджера, клиентские подборки, заявки, кабинет покупателя и сведения продавца. Рабочий домен: https://wheels.imkonex.com. Эта сборка относится только к `imkonex-cars/imkonex-wheels`, не к каталогу автомобилей.

## Обновление существующего магазина

Полный пакет содержит `START_HERE.md`, `APPLY_TO_PROJECT.py` и контрольные суммы. Сначала примените установщик к свежей локальной копии GitHub. Он сохраняет текущие товары, фото и настройки, проверяет совместимость исходников и готовит отдельную папку для загрузки. **Не удаляйте репозиторий и не заменяйте рабочую выгрузку данными из архива.**

После загрузки всех исходников и успешных проверок последнего коммита:

```bash
wheels backup
wheels update --include-code
wheels status
curl --fail --silent --show-error --max-time 20 https://wheels.imkonex.com/build-info.json
```

Выполняйте следующую команду только после успешного завершения предыдущей. Ожидаемая версия — `0.9.0`.

## Что включено

- Каталог, фильтры зимних шин «Шипы / Без шипов», выбор производителей, подбор разных размеров по осям, карточки с характеристиками и фотографиями.
- Адаптивная витрина, общая шапка/подвал, виджет связи, клиентские подборки без закупочных цен.
- Защищённый кабинет менеджера: закупочные цены, цены продажи, наценки, склады и заявки. Минимальная разница с закупкой — 100 ₽ за единицу до расходов.
- Кабинет покупателя и серверный вход по СМС при настройке провайдера. Только собственные заявки, созданные при авторизованном оформлении; гостевые заявки не привязываются по совпадению телефона.
- Контакты и реквизиты ООО «ИНВЭКС», доставка, оплата, возврат, условия заказа, конфиденциальность и отдельное согласие. Фактический адрес: 454080, г. Челябинск, пр. Ленина, 89, оф. 522.
- Исправления синхронизации API, сохранение предыдущей выгрузки при ошибке, автоматические проверки GitHub. Автоматическая публикация в Render удалена.

## Границы готовности

**Работает процесс заявки с подтверждением менеджера. Онлайн-оплата не подключена.** СБП, банковский кредит и CloudKassir требуют отдельной реализации и проверки платёжного цикла, возвратов и чеков. Долями и рассрочка магазина не предлагаются.

СМС требует серверного ключа, настроенного провайдера и проверки доставки: [инструкция](docs/CUSTOMER_SMS_AUTH.md). Без настройки отправка кода недоступна и не имитируется.

Профили закупающих юридических лиц — предварительный просмотр. Они не переключают действующую отправку заказа через общую учётную запись поставщика. Приём SOAP-уведомлений выключен по умолчанию; автоматическая обработка статусов и выдача QR клиенту не реализованы. Не включайте закупки без проверки договора, customerID, склада и адреса.

Вложенная публичная выгрузка от 22.09.2026 содержит 20 359 товаров (шины и диски). Код для других категорий включён, но наличие реальных камер, датчиков, масел и расходников появится только после успешной синхронизации. Неизвестные характеристики, включая страну изготовления, не выдумываются.

Подробности: [RELEASE_NOTES.md](RELEASE_NOTES.md), [сведения для проверки магазина](docs/STORE_REQUIREMENTS.md). Старые документы с номерами 0.5–0.8 сохранены как история, а не как инструкция текущего обновления.

## Разработка и сборка

Текущая архитектура сохранена: FastAPI/Python, JavaScript, SQLite на постоянном приватном томе, Docker + Caddy. Переписывание на Next.js в эту сборку не входит.

```bash
npm ci
npm run check
npm test
node BUILD_RENDER.mjs
python -m pip install -r requirements-dev.txt
python -m pytest -q tests
```

`BUILD_RENDER.mjs` — существующее имя сборщика, он также используется в Docker на REG.ru. `dist`, зависимости и приватная БД в GitHub не загружаются. Для рабочей витрины и кабинетов используется `Dockerfile.portal` и `backend.portal:app`; запуск только статического `dist` не включает API.

Основные настройки сервера перечислены в `.env.example`; значения секретов задаются только в закрытом окружении. Действующая конфигурация `/etc/imkonex-wheels/portal.env` и база `/opt/imkonex-wheels-state/data/manager.sqlite3` сохраняются при штатном обновлении.
