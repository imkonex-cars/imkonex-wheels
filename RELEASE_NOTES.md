## Данные и безопасность обновления

Установщик не заменяет `data/*`, фотографии, `frontend/data/catalog.js`, `.env`, БД и `.git` существующего проекта. Изменённые неизвестным образом исходники останавливают установку до записи. Сохранение данных проверено на копии фактического `main` GitHub от 24.09.2026 (`01910bdb09b3d45903323f97c8630ee3d5d7583d`).

Полный источник включает снимок 20 359 товаров от 22.09.2026: 7 055 шин и 13 304 диска. Это резерв состава проекта, а не актуальная коммерческая выгрузка. В нём нет товаров остальных категорий и подтверждённых стран изготовления; сборка не создаёт их искусственно.

Секреты СМС, API поставщика, банков и кассы не входят в пакет. Настройки, которые ранее разрешали отправку заказов поставщику, не изменяются установщиком. Проверьте их перед реальными закупками. Выбор компании на странице предварительного просмотра не меняет общую учётную запись старого механизма закупки.

## Совместимость

Репозиторий: `imkonex-cars/imkonex-wheels`. Сервер: существующая конфигурация REG.ru `wheels`. Python 3.12, Node.js 22, Dockerfile.portal. Обновлены GitHub Actions; задания используют Ubuntu 24.04. Имя `BUILD_RENDER.mjs` оставлено для совместимости. Сервис Render автоматически не обновляется этой сборкой.

Не заменяйте исходники каталога автомобилей и настройки Tilda файлами этой сборки. Общая шапка/подвал подключаются прежним механизмом. Соответствие внешних ссылок в общей шапке требованиям банка нужно согласовать отдельно.
